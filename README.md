# اختبار السلامة الرقمية للمعلمين — النسخة التجريبية

- 15 سؤالاً متقدمة ومتنوعة.
- النجاح: 11 من 15 (70%).
- عند النجاح تظهر شهادة المدرسة المرفقة.
- اسم المعلم يُكتب تلقائياً في المكان المخصص في الشهادة.
- تاريخ الشهادة ثابت كما في القالب: 9-10-2026.
- متوافق مع iOS وAndroid.
- لا يحتاج إلى قاعدة بيانات أو مكتبات خارجية.

## تشغيل النسخة التجريبية
افتح `index.html` على الهاتف أو الكمبيوتر.

## GitHub Pages
ارفع `index.html` وصورة الشهادة إلى المستودع، ثم فعّل GitHub Pages من:
Settings → Pages → Deploy from a branch → main → /(root)
